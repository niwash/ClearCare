ClearCare is an interactive web application that makes HIQA nursing home inspection reports easier to search, understand, track, and compare. It ingests publicly available HIQA inspection PDFs, extracts regulation-level compliance judgements, and presents each nursing home’s compliance history in a structured format.

Users can search and filter nursing homes by location, amenities, and preferences, create shortlists, and compare homes side by side. ClearCare also provides the inspector’s original comments and source reports behind each judgement.
