We split each stored Section 1 response into commitments using sentence, paragraph, numbered-item and bullet boundaries with explicit action words. Each commitment keeps an exact span with zero-based character offsets and an exclusive end, its PDF pages, any single named sub-regulation and the provider's stated deadline. V6 stores append-only rows tied to the response ID and splitter version; the API view supplies the report, regulation and extractor version from that response. A separate stage, which the scheduler runs after text extraction so that nothing is run by hand, reads stored responses and the page offsets retained by V5. It does not read PDFs or depend on the current text mapping.

Keeping a response whole would combine commitments with different stated deadlines. These rules keep surrounding context with the detected actions and return the entire response without a date when no action is detected. They do not read Section 2's compliance dates or infer a reported outcome. CCARE-114's pilot will compare these spans with a later method.

Repeat runs add nothing at the same splitter version. Rules-v3 replaces the earlier list-marker and label rules while retaining rules-v1 and rules-v2 rows. Blank lines and new action paragraphs end list context. Explicit dated list introductions supply a shared date only to their following list items. Dates require a deadline cue tied to the commitment clause, such as by, before, within, will be completed on, or a Timeframe or Time Frame label. Historical dates introduced only by on are not deadlines, and a label whose date does not follow it directly, such as Time Frame: Completed 31/7/2024, gives no cue. Full named-month and numeric dates are supported. Month-year dates use the month's last day with month precision and the printed form retained. Relative dates and uncertain relationships remain unparsed, with their printed wording preserved in the exact source span. Sentence rules can still combine actions or include context, so the retained spans support human review and later comparison with the pilot.
