# The pipeline schedules itself in Compose

The pipeline runs as a long-running service in the root `compose.yaml`, next to the database and the API. A small scheduler, `clearcare_pipeline.schedule`, runs its stages one at a time. It takes a register snapshot once a day, and downloads the inspection reports once a week, or a day after a failed attempt. When it starts, and after every download, failed or not, it copies new files to the bucket if one is set. It loads the register and then the reports into the database when it starts, the register after each register snapshot, and the reports after each report download. Before it contacts HIQA, it writes the job's next attempt to a file in the data directory, so a restart cannot bring a crawl forward. `CLEARCARE_CRAWL` turns the downloads on, for one county or for every centre. It is off by default, and then the pipeline only uploads and loads what its data directory already holds.

Before this, a systemd timer on the VM (CCARE-17) took the register snapshot, and reports were downloaded by hand, one county at a time, so only the VM ran the pipeline on a schedule. Now the VM runs the same Compose file, with its own settings on top (`infra/deploy`), and any other machine with Docker runs the database, the API and the pipeline with `docker compose up`. The schedule is Python code with tests, like the stages.

The scheduler's failures show in its log and in its state file. The state file records only the outcome of each download; upload and load failures are only in the log. Jobs run a day or a week after the last attempt, where the timer ran at 06:00 UTC. A stage has no time limit, so one that hangs holds up the others.

A second timer for reports would have kept the pipeline tied to the VM. Cron inside the container would start jobs at fixed times, but it would not wait a day after a failed crawl or catch up after the machine was off, so we would still write that code. Crawling is off by default because each copy of the project crawls HIQA on its own, and a fresh clone should not start a national crawl.
