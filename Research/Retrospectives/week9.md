# Week 9 Retrospective

## What went well this week

The website made good progress this week, with more features added, including maps and images. Team collaboration went well, and many of the design suggestions were applied to the site, making this a strong week for design collaboration. The user evaluation report was also finished, and there is now a clearer path for it going forward.

## What didn’t go well this week

We are still lacking user input for the evaluation, and the user evaluation report lacked evidence of the changes made to the site, such as screenshots. There have been more late PRs this week, which led the team to starting work later than earlier in the afternoon. Although the team completed the user evaluation report, the presentation was lacking and there was more potential to it.

## What can we improve on

The team agreed that we need more evidence of changes, so changes to the website should be tracked for the user evaluation. We also need more user feedback, which means employihaving better outreach techniques for getting user input. The structure of the user evaluation can be improved, and we should consider other ways to obtain qualitative data.

## What we will do next week

Next week, the team will finish the gold set, fix bugs and issues, and continue improving the site's UX/UI. We will also work on alerts and on the research questions.
